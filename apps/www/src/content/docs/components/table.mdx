## Overview

The Table component is a powerful, production-ready data display component built for complex data presentation scenarios. It combines a modern glassmorphism aesthetic with enterprise-grade features including multi-column sorting, multi-select filtering, debounced search, internal/external pagination, expandable metric rows, sticky columns, and comprehensive state handling (loading, error, empty, row-level empty).

### Key Capabilities

- **Sorting**: Multi-column with visual indicators, controlled/uncontrolled modes
- **Filtering**: Multi-select dropdown filters with "All" option and clear actions
- **Search**: Debounced (300ms) search with 3-character minimum, clearable input
- **Pagination**: Internal (client-side) or external (server-side) with page size, go-to-page
- **Sticky Columns**: First column (service) and last column (actions) stay visible during horizontal scroll
- **Expandable Rows**: Metric columns collapse into a single expandable message row when empty
- **Custom Rendering**: Per-cell render functions with full row context
- **States**: Skeleton loaders, error display, empty states, row-level empty messages
- **Row Interactions**: Hover highlight, click handlers, keyboard navigation
- **Accessibility**: ARIA labels, focus management, keyboard sortable headers, screen reader announcements

## Quick Start

```tsx
import Table, { ColumnDef } from "@workspace/ui/components/mui-components/ts/Table";

const columns: ColumnDef<User>[] = [
  { key: "name", label: "Name", minWidth: 150, sortable: true, sortKey: "name" },
  { key: "email", label: "Email", minWidth: 200 },
  { key: "role", label: "Role", minWidth: 120 },
  { key: "status", label: "Status", minWidth: 100, sortable: true, sortKey: "status" },
];

const data: User[] = [
  { name: "Alice Johnson", email: "alice@example.com", role: "Admin", status: "Active" },
  { name: "Bob Smith", email: "bob@example.com", role: "User", status: "Active" },
  { name: "Carol White", email: "carol@example.com", role: "User", status: "Inactive" },
];

export default function UserTable() {
  return (
    <Table
      title="Users"
      subtitle="System accounts and permissions"
      data={data}
      columns={columns}
      pageSize={10}
    />
  );
}
```

## API Reference

### Table Props

| Prop | Type | Default | Purpose |
|------|------|---------|---------|
| **Data & Columns** |
| `data` | `T[]` | `[]` | Array of row objects to display |
| `columns` | `ColumnDef<T>[]` | `[]` | Column definitions (key, label, render, sortable, etc.) |
| **Pagination** |
| `pageSize` | `number` | `10` | Number of rows per page (internal pagination) |
| `externalPagination` | `boolean` | `false` | Enable server-side pagination mode |
| `currentPage` | `number` | `1` | Current page (controlled, for external pagination) |
| `totalPages` | `number` | `1` | Total pages (required for external pagination) |
| `onPageChange` | `(page: number) => void` | - | Callback when page changes (external mode) |
| **Sorting** |
| `sortColumn` | `string \| null` | `null` | Currently sorted column key (controlled) |
| `sortAsc` | `boolean` | `false` | Sort direction (true = ascending) |
| `onSortChange` | `(key: string \| undefined) => void` | - | Callback when sort column changes |
| **Filtering** |
| `filters` | `FilterConfig[]` | `[]` | Filter dropdown configurations (key, label, options[]) |
| `initialFilterValues` | `Record<string, string[]>` | `{}` | Initial filter state for SSR/hydration |
| `onFilterChange` | `(value: string) => void` | - | Primary filter change callback (index 0) |
| `onSecondaryFilterChange` | `(value: string) => void` | - | Secondary filter callback (index 1) |
| `onTertiaryFilterChange` | `(value: string) => void` | - | Tertiary filter callback (index 2) |
| `showUnscannedFilter` | `boolean` | `false` | Show "Unscanned Services" toggle button |
| `onUnscannedFilterChange` | `(active: boolean) => void` | - | Callback for unscanned filter toggle |
| **Search** |
| `searchable` | `boolean` | `false` | Enable search input in header |
| `searchKeys` | `string[]` | `columns.map(c => c.key)` | Column keys to search against |
| `onSearch` | `(query: string) => void` | - | Debounced search callback (300ms, 3-char min) |
| **States** |
| `loading` | `boolean` | `false` | Show skeleton loaders instead of data |
| `skeletonRows` | `number` | `10` | Number of skeleton rows to render |
| `error` | `string \| null` | `null` | Error message to display in table body |
| `emptyMessage` | `string` | `"No data available."` | Message when no rows match filters/search |
| `noDataRowMessage` | `string` | `"No data is available for the selected date."` | Message for rows where `isRowEmpty` returns true |
| `isRowEmpty` | `(row: T) => boolean` | Checks `row._raw?.has_data === false` | Determines if a row should show empty state |
| **Header & Branding** |
| `title` | `React.ReactNode` | - | Main table title |
| `subtitle` | `React.ReactNode` | - | Subtitle below title |
| `icon` | `string` | `"ri-settings-3-line"` | Remixicon class for header icon |
| `tooltip` | `string` | - | Tooltip text on title (shows info icon) |
| **Styling & Customization** |
| `sx` | `Record<string, unknown>` | `{}` | Additional MUI Box sx props for container |

## ColumnDef Props

| Prop | Type | Required | Purpose |
|------|------|----------|---------|
| `key` | `string` | **Yes** | Unique key matching data object property |
| `label` | `React.ReactNode` | **Yes** | Column header text/element |
| `subtitle` | `string` | No | Secondary text below header |
| `minWidth` | `string \| number` | No | Minimum column width (px or %) |
| `align` | `"left" \| "center" \| "right"` | No | Cell text alignment (default: center) |
| `sortable` | `boolean` | No | Enable click-to-sort on header |
| `sortKey` | `string` | No* | Data key for sorting (defaults to `key`) |
| `isMetricColumn` | `boolean` | No | Marks as collapsible metric column for empty rows |
| `cellStyle` | `React.CSSProperties` | No | Inline styles applied to all cells in column |
| `render` | `(value: unknown, row: T) => React.ReactNode` | No | Custom cell renderer function |

> *Required when `sortable: true`

### FilterConfig Props

| Prop | Type | Required | Purpose |
|------|------|----------|---------|
| `key` | `string` | **Yes** | Matches data property key to filter on |
| `label` | `string` | **Yes** | Filter dropdown button label |
| `options` | `string[]` | **Yes** | Array of filter option values (excludes "all") |

## Best Practices

### Column Configuration
- **Use `minWidth`** for predictable layouts. Avoid fixed widths; let content breathe.
- **Set `sortKey` explicitly** when sorting key differs from column `key`.
- **Use `align: "left"`** for text identifiers (names, IDs), `"right"` for numbers, `"center"` for status badges.
- **Mark metric columns** with `isMetricColumn: true` for automatic empty-row collapsing.

### Sorting
- **Controlled mode**: Pass `sortColumn`, `sortAsc`, and `onSortChange` for URL sync or server-side sort.
- **Uncontrolled mode**: Omit sort props for internal state management.
- **Default sort**: Initialize `sortColumn` and `sortAsc` for initial sorted view.

### Filtering
- **Provide `initialFilterValues`** for SSR/hydration to avoid layout shift.
- **Use descriptive `label`** for filter dropdowns; users see this, not the `key`.
- **Filter options** should match data values exactly (case-insensitive comparison is used).
- **Limit to 3 filters** in header; additional filters move to a filter panel.

### Search
- **Debounce is built-in** (300ms, 3-char minimum). Don't add external debouncing.
- **Customize `searchKeys`** to limit search to relevant columns (performance).
- **Use `onSearch`** for server-side search; fires after debounce with current query.

### Pagination
- **Internal pagination**: Default. Set `pageSize` for rows per page.
- **External pagination**: Set `externalPagination={true}`, provide `currentPage`, `totalPages`, `onPageChange`.
- **Page resets automatically** when filters, search, or data change.

### Sticky Columns
- **First column key must be `service`** for left-sticky behavior.
- **Last column key must be `_action`** for right-sticky behavior.
- **Shadows** are applied automatically for visual separation.

### Empty Rows
- **Implement `isRowEmpty`** to detect rows with no metric data.
- **Customize `noDataRowMessage`** for context-aware empty messaging.
- **Metric columns** (`isMetricColumn: true`) collapse into single message cell.

### Performance
- **Memoize `columns`** and `data` with `useMemo`/`useCallback` to prevent re-renders.
- **Virtualize** for 1000+ rows (not built-in; wrap with react-window).
- **Server-side** filtering/sorting/search for large datasets.

## Accessibility

The Table component follows WAI-ARIA Data Grid pattern:

### Keyboard Navigation
| Key | Action |
|-----|--------|
| `Tab` | Move between interactive elements (headers, filters, search, pagination) |
| `Enter` / `Space` | Activate sort on focused header |
| `Arrow Left/Right` | Navigate between pagination buttons |
| `Enter` | Activate focused pagination button |
| `Escape` | Close open filter dropdowns |

### ARIA & Semantic Markup
- **Table structure**: `<table>`, `<thead>`, `<tbody>`, `<th>`, `<td>` semantics preserved
- **Column headers**: `scope="col"` on `<th>`, `aria-sort` on sortable headers (`ascending`, `descending`, `none`)
- **Filter dropdowns**: `aria-haspopup="listbox"`, `aria-expanded`, `aria-controls`
- **Search input**: `aria-label="Search"`, `aria-describedby` for hints
- **Pagination**: `aria-label="Pagination"`, `aria-current="page"` on active page
- **Row hover**: No ARIA needed; visual only

### Screen Readers
- Sort announcements: "Sorted ascending by Column Name"
- Filter announcements: "Filter Status changed, 2 options selected"
- Pagination announcements: "Page 2 of 5"
- Loading state: "Loading data" via skeleton `aria-busy="true"`
- Error state: `role="alert"` on error message

### Focus Management
- Focus visible on all interactive elements (4px outline, accent color)
- Focus trapped in filter dropdowns (Tab cycles within)
- Focus returns to trigger on dropdown close
- Skip links not needed; tab order follows visual order
