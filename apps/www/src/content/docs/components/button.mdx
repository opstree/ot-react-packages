## Overview

The Button component is designed for maximum visual impact. It utilizes a custom noise background animation and vibrant gradients to create a truly premium feel. It's perfect for primary call-to-actions and hero sections.

## Installation

<InstallationCli value="opscli add button"/>

### Variant Themes

| Variant | Colors | Use Case |
|---------|--------|----------|
| `default` | Pink, Blue, Yellow | General purpose, playful |
| `emerald` | Green, Cyan, Lime | Success actions, finance, nature |
| `fire` | Orange, Red, Purple | Destructive actions, warnings, energy |
