## Installation

<Heading title="Add Utilities" subtitle="Install the required dependencies for class name utilities." className="mb-4"/>

### Install dependencies

<InstallationCli value="npm i motion clsx tailwind-merge" />

### Add util file

Create a `lib/utils.ts` file with the `cn` helper function:

```ts title="lib/utils.ts"
import { ClassValue, clsx } from "clsx";
import { twMerge } from "tailwind-merge";

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
```

<Callout type="info" title="Copy Code">
Click the copy button in the top-right corner of the code block to copy the utility function.
</Callout>

## Next.js 15 and React 19 Framer Motion Fix

<Heading title="Next.js 15 + React 19 Compatibility" subtitle="Required configuration changes for using Framer Motion with React 19." className="mt-10 mb-4"/>

### Using framer-motion

If you're using Next.js 15 and React 19 with `framer-motion`, add the following to your `package.json`:

```json title="package.json"
{
  "dependencies": {
    "framer-motion": "^12.0.0-alpha.1",
    "next": "15.0.3",
    "react": "19.0.0-rc-66855b96-20241106",
    "react-dom": "19.0.0-rc-66855b96-20241106",
    "tailwind-merge": "^2.5.5"
  },
  "overrides": {
    "framer-motion": {
      "react": "19.0.0-rc-66855b96-20241106",
      "react-dom": "19.0.0-rc-66855b96-20241106"
    }
  }
}
```

### Using motion (new package)

If you're using the new `motion` package instead of `framer-motion`:

```json title="package.json"
{
  "dependencies": {
    "motion": "^12.0.0-alpha.1",
    "next": "15.0.3",
    "react": "19.0.0-rc-66855b96-20241106",
    "react-dom": "19.0.0-rc-66855b96-20241106",
    "tailwind-merge": "^2.5.5"
  },
  "overrides": {
    "motion": {
      "react": "19.0.0-rc-66855b96-20241106",
      "react-dom": "19.0.0-rc-66855b96-20241106"
    }
  }
}
```

<Callout type="warning" title="Important">
The `overrides` field is required to ensure Framer Motion uses the correct React 19 version. Without this, you may encounter compatibility issues.
</Callout>
