<Heading title="Add util file" subtitle="Create a `lib/utils.ts` file with the `cn` helper function:" className="mt-10 mb-2"/>

<CodeBlock lang="json" title="lib/utils.ts" code={`import { ClassValue, clsx } from "clsx";
import { twMerge } from "tailwind-merge";

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
`}
/>

<Heading title="Next.js 15 + React 19 Compatibility" subtitle="Required configuration changes for using Framer Motion with React 19." className="mt-10 mb-4"/>

<Heading className="mb-2" title="Using motion" subtitle="If you're using Next.js 15 and React 19 with `framer-motion`, add the following to your `package.json`:"/>

<CodeBlock lang="json" title="package.json" code={`{
  "dependencies": {
    "framer-motion": "^12.0.0-alpha.1",
    "next": "15.0.3",
    "react": "19.0.0-rc-66855b96-20241106",
    "react-dom": "19.0.0-rc-66855b96-20241106",
    "tailwind-merge": "^2.5.5"
  },
  "overrides": {
    "framer-motion": {
      "react": "19.0.0-rc-66855b96-20241106",
      "react-dom": "19.0.0-rc-66855b96-20241106"
    }
  }
}
`} />

<Heading className="mb-2" title="Using motion (new package)" subtitle="If you're using the new `motion` package instead of `framer-motion`:"/>
<CodeBlock lang="json" title="package.json" code={`{
  "dependencies": {
    "motion": "^12.0.0-alpha.1",
    "next": "15.0.3",
    "react": "19.0.0-rc-66855b96-20241106",
    "react-dom": "19.0.0-rc-66855b96-20241106",
    "tailwind-merge": "^2.5.5"
  },
  "overrides": {
    "motion": {
      "react": "19.0.0-rc-66855b96-20241106",
      "react-dom": "19.0.0-rc-66855b96-20241106"
    }
  }
}
`} />

<Callout type="warning" title="Important">
The `overrides` field is required to ensure Framer Motion uses the correct React 19 version. Without this, you may encounter compatibility issues.
</Callout>
